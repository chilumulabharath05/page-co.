# 🌐 PageCo — Modern Landing Page

A clean and responsive **landing page website** built using modern frontend technologies. Designed to provide a smooth user experience with a visually appealing interface.

---

## 🚀 Live Demo

👉 https://page-co-delta.vercel.app/

---

## ✨ Features

- 🎨 Modern UI with clean design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Fast loading and optimized performance
- 🧩 Component-based structure
- 🌈 Smooth layout and visual styling

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/chilumulabharath05/page-co.git
cd page-co
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```
